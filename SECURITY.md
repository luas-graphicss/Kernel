# Segurança

[English](SECURITY.en.md)

Relate uma vulnerabilidade pelo relato privado do GitHub, na aba Security deste repositório. Se a opção não aparecer, abra uma issue pedindo um canal privado, sem descrever a falha.

O que conta como falha de segurança, como ela é tratada e quais versões recebem correção está em [docs/security/vulnerability-response.md](docs/security/vulnerability-response.md). O modelo de ameaça está em [docs/security/threat-model.md](docs/security/threat-model.md).
