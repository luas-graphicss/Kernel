# Security

[Português](SECURITY.md)

Report a vulnerability through GitHub's private reporting, in the Security tab of this repository. If the option does not appear, open an issue asking for a private channel, without describing the flaw.

What counts as a security flaw, how it is handled and which versions receive a fix is in [docs/security/vulnerability-response.en.md](docs/security/vulnerability-response.en.md). The threat model is in [docs/security/threat-model.en.md](docs/security/threat-model.en.md).
