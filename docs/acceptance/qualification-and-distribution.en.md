## First-use fixes

| Problem | Resolution |
| --- | --- |
| Spaces in paths caused generic Make failures | Preflight rejects repository, build or cache paths containing spaces, names the path and returns status 3. README documents the requirement; space-containing paths are not claimed as supported |
| First byte lost from redirected input before boot | `run` holds piped/file stdin until `shell: ready` |
| More than four pasted lines disappeared silently | Complete-line drops emit `console: dropped-lines=N`; queue limits and script pacing are documented |
| Overlong lines executed truncated | Lines exceeding 255 bytes return `MESSAGE_TOO_LARGE`; Ctrl-U permits restarting |
| TAB and arrows contaminated commands | TAB becomes a space; whole escape sequences are discarded |
| Missing `cc` or `gcc` produced generic errors | Preflight checks `make`, `cc` and `gcc`, naming missing tools with status 3 |
| Refused `write` left an empty new file | Shell removes the file it just created when the write is rejected; existing files are not removed |
| `str` `%` formatting was undocumented | Runtime matrix records its absence and recommends `str.format` or f-strings |
| Qualification presented old images as current | This record updates values, preserves the historical link and ties results to actual hashes |

The native serial ring remains limited to 256 bytes: a burst filling it may lose bytes before the console service without an operator warning. Scripts must wait for each command status. On an interactive terminal, type after the prompt; pre-boot input buffering applies specifically to redirected stdin.

## Gates and distribution

Passed: `correctness`, `boot`, `lifecycle`, `isolation`, `durability`, `network`, `dependencies`, `distribution`, `interfaces`, `budgets`. Still open: `stability`, `fuzzing`.

The `kernel-1.0.0rc1-qemu-riscv64` bundle contains images, manifest, profile, toolchain lock, `SHA256SUMS`, license inventory, SPDX 2.3 SBOM and release report. Its manifest retains `qualified: false`. There is no production release signature, and no key was created or committed for this publication.

For a stable version, using these same images:

```sh
uv run kernel-tool fuzz --all --budget-hours 24
uv run kernel-tool soak --profile qemu-riscv64 --hours 24
uv run kernel-tool release-check --profile qemu-riscv64
```

The soak must complete 24 hours in one boot. Fuzzing accumulates per family and code version in `build/fuzz/ledger.json`. An image change also requires regenerating other reports for its new hashes. See the [release procedure](../operations/release-procedure.en.md).
